# SpeakingBot — Practice & Assessment Platform

A modern React/Vite practice-test platform inspired by common online assessment workflows. Built as an original implementation with an interactive test engine, dashboard, results, bookmarks, and admin-style content management UI.

## Run locally

```bash
npm install
npm run dev
```

## Build

```bash
npm run build
npm run preview
```

## Note

This first version is a client-side MVP using localStorage for demo persistence. Production authentication, server-side scoring/timers, MongoDB, payments, and real admin APIs should be added behind the current UI/service boundaries before public deployment.
